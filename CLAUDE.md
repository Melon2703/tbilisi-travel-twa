## Claude Code & Engineering Skills

Skills are located in `.claude/skills/` (symlinked to `.agents/skills/`).

### Key Slash Commands:
- `/setup-matt-pocock-skills` — Configure issue tracker, triage labels, and domain doc layout.
- `/grill-with-docs` — Interview mode to sharpen ideas and record decisions in `CONTEXT.md`.
- `/to-spec` & `/to-tickets` — Break down specs into tracer-bullet tickets under `.scratch/` or GitHub.
- `/implement` — Build tickets using TDD and automated code review.
- `/diagnosing-bugs` — Diagnose hard bugs with tight feedback loops before fixing.
- `/tdd` — Test-driven development slice-by-slice.
- `/code-review` — Two-axis review (Standards + Spec) of diffs.
- `/ask-matt` — Map and guide for all engineering skills.
